# Sync Box

Plugin gratuito para o Adobe Premiere Pro, por [Sales Wed.](https://www.instagram.com/saleswed_/)

Toda música, vídeo e efeito sonoro que você importa no projeto vai sozinho para a pasta do projeto, cada um na sua gaveta (`MIDIA IMPORTADA/MUSICAS`, `EFEITOS SONOROS`, `VIDEOS`, `IMAGENS`, `GRAFICOS`). O clipe no Premiere é religado para a cópia, sem importar de novo. Na hora de levar o projeto para outro HD, não falta nada. Funciona sem internet.

## Baixar

Página de download: https://apps.weddingflow.com.br/syncbox/

Ou direto pelas [versões](../../releases/latest):

- **Mac** (Premiere Pro 2024+): `SyncBox-Mac.zip`
- **Windows** (Premiere Pro 2024+, Windows 10 e 11): `SyncBox-Windows.zip`

Abra o zip, rode `Instalar Sync Box` e, no Premiere, vá em **Janela › Extensões › Sync Box**.
